# Mohit Raj — Developer Portfolio

Modern, responsive single-page developer portfolio website built with React, TypeScript, and Vite.

## Live Links
- **GitHub Repository**: [https://github.com/rajmohit21/Finflow-Loan-Management-System](https://github.com/rajmohit21/Finflow-Loan-Management-System)
- **LinkedIn**: [https://www.linkedin.com/in/mohit-raj-/](https://www.linkedin.com/in/mohit-raj-/)

## Tech Stack
- React 18
- TypeScript 5
- Vite
- Vanilla CSS3 Design System
- Bootstrap Icons

## Local Execution
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
Vercel deployment output: `dist/`
